What is youki?

  • Low-level OCI runtime — the layer that actually creates containers on Linux
  • Written in Rust — memory safe, no garbage collector, C-level performance
  • Name 容器 = “container” in Japanese
  • Drop-in replacement for runc — same CLI interface, same OCI spec
  • Works with Podman, Docker, containerd — nothing above it changes

How youki Works

StepAction
1. Parse Read config.json → validate OCI spec
2. Prepare Create state dir, set up rootfs, spec validation
3. Fork clone(2) with namespace flags → child process
4. Setup Mount rootfs, configure cgroups, apply seccomp
5. Exec pivot_root → drop caps → execve(entrypoint)
6. Track Write PID + state, set up hooks, report back

↳ Tip: demonstrate with strace -f -e clone,execve to watch every syscall live

The Borrow Checker in Action

// borrow checker prevents entire classes of security bugs at compile time
fn setup_namespaces(spec: &Spec) -> Result<()> {
    // compiler tracks ownership — ns cannot outlive spec
    let ns = spec.linux().namespaces();  // Option<&Vec<..>>
    for namespace in ns.iter().flatten() {
        unshare_or_setns(namespace)?;  // ? = propagate error up immediately
    }
    Ok(())
}
  • ? operator — propagates errors at every syscall; no silent failures
  • Ownership prevents use-after-free — enforced at compile time, not runtime
